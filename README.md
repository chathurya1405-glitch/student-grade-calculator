# Student Grade Calculator 🎓

A beginner-friendly Python program that calculates a student's total marks, percentage, and grade.

## 📌 Features

- Takes the student's name
- Accepts marks for 3 subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade based on percentage

## 🐍 Concepts Used

- Variables
- `input()`
- `float()`
- Arithmetic operations
- `if-elif-else` conditions
- `print()`

## 🚀 How It Works

1. Enter the student's name.
2. Enter marks for Maths, Python, and Data Science.
3. The program calculates the total and percentage.
4. It displays the corresponding grade.
